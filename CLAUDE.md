# Community Dealer – сайт-MVP

Автосалон премиальных авто в Москве (бывш. Ultima Motors), ВТБ Арена Парк, Ленинградский пр-т 36 с36.
Сайт показной: GitHub Pages `tema-mail.github.io/community-dealer`, закрыт от индексации (`PUBLIC_NOINDEX=1`).

## Стек и команды
- Astro 7 + Preact (острова: `HeroSlider`, `Gallery`). `npm run build`, `npm run dev`.
- Подпапка Pages задаётся `PUBLIC_BASE` в workflow. Все ссылки и картинки – только через `url()`/`img()` из `src/data/site.ts`.
- Склад: `python3 scripts/scrape_autoru.py` (auto.ru, нужен Chrome) → `src/data/autoru.json` → `python3 scripts/build_data.py` → `src/data/cars.json`.
- Фото: `python3 scripts/photos.py <папка-кэш вне репо>` → `public/img/cars/<id>/NN-{800,1200}.webp`; номера ищет `scripts/plates.swift` (Vision macOS). После прогона – глазами проверить первые 8 кадров каждой машины.
- Заявки: `PUBLIC_LEAD_ENDPOINT` (POST JSON). Не задан – форма отдаёт готовое сообщение в WhatsApp.

## Правила
- Номер на фото всегда размыт (там табличка со старым названием ULTIMA MOTORS) – это делает `scripts/photos.py`.
- Стиль: раскладка bork.ru (каталог, карточки, перелистывание первого экрана), цвета Community – чёрный, хром, зелёный `--green*`.
- Каталог: на телефоне 2 карточки в ряд, с 1024 px – 3; в фильтре первым чип «Все», выбор прячет неподходящие.
- Только короткое тире «–».
